# Dados Desglosados

Calcula sumas exactas, mínimas y máximas de dados iguales con un modificador. Distribución completa y recuentos enteros, sin simulaciones aleatorias.

GitHub Pages: main, raiz. https://ilga25.github.io/dados-desglosados/

Fuentes estaticas sin dependencias. Pruebas del motor: work/ten-tools/check.cjs. Guia propia, privacidad y sitemap incluidos. Sin garantia de trafico, indexacion, aprobacion publicitaria o ingresos.
