Probabilidad de dados con modificador y distribución completa

Explora cómo cambia la probabilidad al añadir dados o un modificador al total. Obtén el porcentaje y los casos favorables de cada suma para juegos de mesa o rol.

Los dados no producen una suma uniforme

Cada cara de un dado justo tiene la misma probabilidad, pero una suma puede obtenerse de distintas formas. Con dos dados de seis caras, siete aparece mediante seis parejas ordenadas y dos solamente mediante una.

Exactamente, al menos o como máximo

Exactamente siete cuenta solo el siete. Al menos siete suma siete y todos los valores superiores. Como máximo siete incluye el siete y los inferiores. Las dos últimas condiciones comparten el resultado objetivo.

El modificador se añade una vez

Con dos dados y un modificador de tres, primero se suman las caras y luego se añade tres. Para obtener diez debes sumar siete en los dados. No se añade el modificador a cada dado individual.

Recuento entero, porcentaje redondeado

La herramienta construye la distribución añadiendo un dado cada vez. Utiliza enteros de precisión arbitraria para contar casos y presenta porcentajes redondeados a cuatro decimales. No realiza tiradas aleatorias.

Reglas que no incluye

Los dados deben tener el mismo número de caras y estar numerados de uno en adelante. No incluye dados sesgados, explosivos, rerolls, ventajas, desventajas o selección de los mejores resultados.

Ejemplo comprobable

Dos dados de seis caras tienen 36 resultados ordenados. Exactamente siete son 6 de 36, aproximadamente 16,6667 %. Al menos siete son 21 de 36, aproximadamente 58,3333 %.
